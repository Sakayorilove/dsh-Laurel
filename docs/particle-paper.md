# 粒子展示台纸色（1.8.5）

控制中心 → 场景与动效 → 展示台纸色。开启「纸色展示台」后拖动「纸色明暗」预览，应用保存；取消、关闭或 Esc 还原打开前的设置。默认关闭以保留已有外观，初始滑条为 55%。只在祀日间生效，切换主题后保留数值。

明暗范围为 0–100：0 使用既有夜间纸色 `#30332f`，65 使用原画纸侧底 `#b8b2a6`，100 回到当前主题侧底色；中间连续插值。沿用 `getSiPaperPalette` 的纸色与纸墨色板。构形粒子和展示区文字随纸底选择前景色；原色板对比不足时改用黑或白以保持至少 4.5:1 的名义色值对比。纹理及粒子透明度会影响实际像素，仍需视觉核验。

复用既有可选纸纤维资源 `native/paper-fibres.png`，hash `7bbcfd3f035ac737858cc5e2ab70f67cc07937567397e11311828993d6c9e1d3`；不增加或再分发私人图片。420×744 的平铺和 .62 不透明度沿用画纸主题。纹理不可用时由现有素材服务提供透明占位，纸色和交互仍可用。许可与可选本机素材边界见 `THIRD-PARTY.md`。

新增偏好 `paperEnabled`、`paperBrightness` 沿用既有场景存储作用域，不修改全局纸张浓淡、壁纸或其他主题。搜索「纸色」可定位；关闭状态定位到开启开关。滑条使用带可见标签的原生 range，支持键盘。

验证：`pnpm test` 覆盖输入校验及全部整数明暗值的前景对比；`node scripts/qa-scene-paper.mjs` 使用实际构建 bundle、WebGL、已留存 rc.5 组件样本和独立偏好存储，验证预览、应用、取消、Esc、重挂载、主题隔离、键盘、搜索和窄窗。样本与本机素材需通过 `LAUREL_QA_REFERENCE`、`LAUREL_QA_MATERIALS` 指定；输出通过 `LAUREL_QA_OUTPUT` 写仓库外。隔离浏览器验证不代表真实客户端安装或冷启动验收。
